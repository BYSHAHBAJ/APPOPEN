Compatibility and responsible use

Available FPS and graphics options depend on the phone’s hardware, operating system, game edition and current game version. Selecting a higher FPS value does not mean every device can maintain that frame rate. Heat, battery use and stability can also change with performance settings.

Before using a configuration tool

  • Read the app’s on-screen instructions and check the target game version.
  • Keep a backup of files before making manual changes.
  • Install games and updates from official publisher channels where possible.
  • Stop using a setting if it causes crashes, overheating or other unexpected behaviour.
