FPS BOOSTER WEBSITE — UPLOAD GUIDE

Files:
- index.html
- assets/ (all screenshots and the logo used by the page)

How to publish:
1. Upload index.html and the entire assets folder to the SAME GitHub repository.
2. Keep the folder name exactly "assets" and keep the filenames unchanged.
3. If using GitHub Pages, enable it in repository Settings > Pages.
4. The images use relative paths such as assets/gameplay-preview.jpg, so they load from the same website/repository path.
5. The APK download button currently points to:
   https://github.com/BYSHAHBAJ/APPOPEN/releases/download/120FPS/FPS.Booster_5.1.0.apk
   Update that URL in index.html when publishing a new APK.

Note: The page describes FPS values as options, not guaranteed device performance. Confirm the APK release URL is still valid before publishing.
